how it works

Three commands. Then it just updates.

1

Add the repository

A one-time step. Flatpak downloads the repository's public key from the .flatpakrepo file and checks every update against it.

flatpak remote-add --if-not-exists \ degenview {{SITE_URL}}/degenview.flatpakrepo
2

Install DegenView

Pick the stable or beta branch, here the {{DEFAULT_CHANNEL}} one. Flathub supplies the Freedesktop runtime the first time you install a Flatpak app.

flatpak install degenview {{APP_ID}}//{{DEFAULT_CHANNEL}}
3

Keep it current

New releases appear here within hours. Update with your software centre or the terminal; the app does not install updates itself.

flatpak update

security

Signed, verified, sandboxed.

Every build is checked, then signed

A bundle is published only if its GitHub release is immutable and its build attestation names the app's release workflow. This repository signs the OSTree commits, and Flatpak refuses an update that does not match the key you added.

A small sandbox

DegenView gets the network for market data and a display. It has no access to your files; the file chooser portal hands over only what you pick. Secrets live in the desktop keyring through the Secret portal.

  • --share=network
  • --share=ipc
  • --socket=wayland
  • --socket=fallback-x11
  • --device=dri
  • --filesystem

To remove it: flatpak uninstall {{APP_ID}} and flatpak remote-delete degenview.
